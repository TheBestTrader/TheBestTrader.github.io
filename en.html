01 / DEFINE

Define the problem

Clarify the data, use case and desired output before deciding which steps need a model and which benefit from explicit rules.

02 / INTEGRATE

Connect the workflow

Connect cleaning, APIs and tool calls to interfaces and deployment, so the model becomes part of a complete workflow.

03 / VERIFY

Verify with evidence

Evaluate quality, latency and resource use separately. Record failures and limitations, then use comparable evidence to guide the next step.
